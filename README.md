# Loan Portfolio Performance & Risk Analytics

## Project Overview

This project aims to analyze loan portfolio performance and credit risk in a simulated digital lending company. It focuses on understanding lending trends, repayment behavior, outstanding balances, and potential credit risk across lending partners.

**Project Status:** In Progress

## Business Problem

A digital lending company needs better visibility into its loan portfolio to monitor business growth, repayment performance, and credit risk exposure.

The goal of this project is to develop an analytical framework and an interactive dashboard that can support data-driven business decisions.

## Project Objectives

1. Analyze monthly loan disbursement trends.
2. Monitor outstanding principal balances.
3. Evaluate repayment performance and overdue loans.
4. Identify delinquency patterns across borrower segments.
5. Compare portfolio performance across lending partners.

## Tools & Technologies

- SQL — Data exploration, transformation, and analysis
- Power BI — Data visualization and dashboard development
- Excel / CSV — Dataset preparation and validation
- GitHub — Project documentation and version control

## Dataset

This project will use synthetic lending data to simulate borrower profiles, loan disbursements, repayment schedules, actual repayments, and lending partners.

All data will be fictional and created solely for portfolio and educational purposes.
